# Italian spelling: professionalizzanti

> 📌 **Session memory** (operational convention). Merged from two duplicate memory files.

## Rule

The correct spelling is **"professionalizzanti"** — ending in **"ti"**, NOT "ni". This has been corrected repeatedly; the **t** is the second-to-last letter.

- ❌ `professionalizzani` (with 'ni')
- ❌ `ProfessionalizzaniDay`, `professionalizzani-days`
- ✅ `professionalizzanti` (with 'ti')
- ✅ `ProfessionalizzantiDay`, `professionalizzanti-days`, `/api/professionalizzanti-days`

## Where this appears

- Entity class: `ProfessionalizzantiDay`
- Database column: `professionalizzanti`
- API endpoint: `/api/professionalizzanti-days`
- Course field: `course.professionalizzanti`
- Constraint H4.1 name

## Context

This is a core domain concept in the Italian vocational school scheduling system. Professionalizzanti courses are specialized vocational training courses taught during stage (internship) periods.

**Mnemonic:** *ti* = **ti** (like in "ti"me), not *ni*.
